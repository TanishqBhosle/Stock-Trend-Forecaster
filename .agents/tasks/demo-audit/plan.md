## Critical Discovery: `VITE_USE_MOCKS=false` Already Set

`frontend/.env` has `VITE_USE_MOCKS=false` and `VITE_API_BASE_URL=http://localhost:8000`. This means the frontend will attempt real API calls on every page. ## P0 — Build-Breaking / Causes Runtime Crash

### P0-1: `training_service.py` reads wrong keys from `train_meta` dict → Training crashes on completion

**File:** `backend/app/services/training_service.py` (lines 249–250)

**Problem:** `train.py::train_lstm_model()` returns a metadata dict with keys:
```python
{
  "best_epoch": best_epoch,
  "best_val_loss": best_val_loss,
  "total_epochs": epoch,
  "loss_type": loss_type,
  "history": [{"epoch":..., "train_loss":..., "val_loss":...}]
}
```
But `training_service.py` reads:
```python
run_record.epochs_trained = train_meta["totalEpochsTrained"]   # KeyError!
run_record.best_val_loss  = train_meta["bestValLoss"]          # KeyError!
```
Also, `training_service.py` saves `training_history.json` with the raw `train_meta` dict (which uses `train_loss`/`val_loss` snake_case keys), but `PerformancePage.jsx` calls `GET /api/evaluation/training-history` and plots `dataKey="trainLoss"` and `dataKey="valLoss"` (camelCase). The chart will render blank.

**Fix A — `training_service.py`** (the crash): Change lines 249–250:
```python
# BEFORE:
run_record.epochs_trained = train_meta["totalEpochsTrained"]
run_record.best_val_loss  = train_meta["bestValLoss"]

# AFTER:
run_record.epochs_trained = train_meta["total_epochs"]
run_record.best_val_loss  = train_meta["best_val_loss"]
```

**Fix B — training_history.json shape** (the blank chart): In `training_service.py`, when saving `training_history.json`, normalize the history list to camelCase keys that the frontend expects:
```python
normalized_history = [
    {"epoch": h["epoch"], "trainLoss": h["train_loss"], "valLoss": h["val_loss"]}
    for h in train_meta["history"]
]
history_payload = {
    "totalEpochsTrained": train_meta["total_epochs"],
    "bestEpoch": train_meta["best_epoch"],
    "bestValLoss": train_meta["best_val_loss"],
    "history": normalized_history
}
with open(staging_dir / "training_history.json", "w") as f:
    json.dump(history_payload, f, indent=2)
```
The existing `training_history.json` artifact in `backend/artifacts/lstm/` will also need to be patched manually (it's the already-trained one from the last run) so the Performance page chart shows up during the demo without retraining.

**Files to modify:**
- `backend/app/services/training_service.py`
- `backend/artifacts/lstm/training_history.json` (manual patch — wrap the existing list in `{history: [...]}` with camelCase keys)

**Verify:** Run `pytest backend/tests/test_v2_features.py -k training` — no KeyError. Confirm `/api/evaluation/training-history` returns `{"history": [{"epoch": N, "trainLoss": X, "valLoss": Y}]}`.

### P0-2: `prediction_service.py` seed reads `test_predictions.json` as a list, but seeding code wraps it in `data.get("predictions", [])` — the existing artifact is a plain list

**File:** `backend/app/services/prediction_service.py` (lines 76–89)

**Problem:** `evaluate.py` writes `test_predictions.json` as a plain JSON **list**: `[{"date": "2024-02-20", ...}, ...]`. But `prediction_service.py::seed_historical_test_predictions()` reads:
```python
data = json.load(f)
if not isinstance(data, list) or len(data) == 0:  # checks list — OK
    return
...
for item in data:  # iterates list — OK
    date_str = item.get("date")
```
Actually on second read, the seed code **does** handle a plain list correctly (the `isinstance(data, list)` check passes). However, `backtest_service.py` reads the same file expecting:
```python
data = json.load(f)
predictions = data.get("predictions", [])  # fails on a plain list → returns []
```
This means `run_backtest()` falls through to `return []` and raises `ValueError: "No prediction records available"` for every POST to `/api/backtest/run` when the DB has fewer than 10 records.

**Fix:** In `backtest_service.py::_load_historical_predictions()`, handle both shapes:
```python
with open(self.test_predictions_path, "r", encoding="utf-8") as f:
    data = json.load(f)
# Handle both plain list and {"predictions": [...]} dict
predictions = data if isinstance(data, list) else data.get("predictions", [])
```

**Files to modify:**
- `backend/app/services/backtest_service.py`

**Verify:** POST `/api/backtest/run` with default params → returns a full result with `equityCurve` populated. The BacktestPage chart renders.

**Fix:** Change `BacktestPage.jsx` default values to `'0.50'` / `'-0.50'` to match the model's actual classification thresholds:

```js
  bearThreshold: '-0.50', // matches settings.BEARISH_THRESHOLD (-0.005)
  ...
}
```
